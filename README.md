# СМДЛЕД — Полный Реестр Проектов

Локальная версия веб-приложения для управления проектами компании СМДЛЕД.

## Функционал
* Ролевая модель (Директор, Менеджер, Наблюдатель)
* Локальная база данных (IndexedDB)
* Шифрование данных (AES-256-GCM)
* Загрузка файлов (договоры, УПД)
* Экспорт (CSV, Excel, PDF)
* Резервное копирование (JSON бэкапы)

## Стек технологий
* HTML5
* CSS3 (Glassmorphism)
* JavaScript (ES6+)
